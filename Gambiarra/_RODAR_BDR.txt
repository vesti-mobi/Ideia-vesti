COMO FOI FEITA A CARGA INICIAL (para referencia)
------------------------------------------------------------------------
O plano original era ler o historico do warehouse VestiHouse (Fabric),
mas a CAPACIDADE FABRIC ESTA PAUSADA:
   "Unable to complete the action because this Fabric capacity is
    currently not active" (erro 24800)
e a subscription Azure aparece como "state": "Disabled" - ou seja, nem
da' pra retomar a capacidade.

Solucao: o historico foi extraido do PROPRIO MODELO do Power BI aberto
(a tabela BDR ja estava importada em memoria, 207.003 linhas ate
2026-06-08), via DAX/ADOMD, e concatenado com a janela da API:

   py scratchpad\export_bdr.py 58304          # modelo PBI -> CSV
   py _bdr_to_bq.py --seed-csv <csv>          # CSV + API -> BigQuery

O script tem os dois caminhos: --seed-fabric (se a capacidade voltar) e
--seed-csv (o que foi usado).

------------------------------------------------------------------------
CONFERENCIA NO BIGQUERY
------------------------------------------------------------------------
SELECT FORMAT_DATE('%Y-%m', dt_ref) mes, COUNT(*) linhas,
       ROUND(SUM(valor_onerado),2) onerado, ROUND(SUM(rebate_financeiro),2) rebate
FROM `vesti-data-499015.vestilake_BI.bdr`
GROUP BY 1 ORDER BY 1
